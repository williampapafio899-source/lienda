# Web App Cost Estimate — store like sarahlawsonimports.com/shop

Scope assumed: product catalogue, cart, checkout with Mobile Money and card
payments, and an admin area to manage products and orders. All prices are
approximate, in USD.

## Option 1: Ready-made store builder (cheapest, fastest)

| Item | Cost |
|---|---|
| Domain (.com) | ~$15/year |
| WooCommerce hosting | ~$5–15/month |
| or Shopify | ~$29–39/month, plus transaction fees |
| Theme | Free–$80 one-time |
| Payments (Paystack or Hubtel: Mobile Money and cards) | ~1.95% per sale |
| Setup by a freelancer | ~$200–800 one-time, or $0 if you do it yourself |

**Total: about $100–$1,000 to launch, then $10–40/month.**
Recommended: WooCommerce with Paystack for a Ghanaian store.

## Option 2: Custom-built web app (Next.js + Postgres/Supabase + Paystack)

| Item | Cost |
|---|---|
| Hosting (Vercel) | Free–$20/month |
| Database (Supabase) | Free–$25/month |
| Image storage (Cloudinary) | Free at small scale |
| Domain | ~$15/year |
| Payments | ~1.95% per sale |
| Development, Ghana-based freelancer | ~$1,000–4,000 |
| Development, agency or overseas developer | ~$5,000–25,000+ |

**Total: about $1,000–$25,000 to build, then $0–50/month to run,** plus
ongoing maintenance.

## What drives the price up

- Customer accounts and order tracking
- Stock management across several locations
- WhatsApp ordering and SMS notifications
- A separate mobile app
- Integrations with delivery services

## Recommendation

Unless you need features the store builders can't do, go with Option 1.
